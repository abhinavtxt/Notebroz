# NotesBroz

A simple starter website for chapter-wise BBA notes.

## GitHub upload

Upload all `.html`, `style.css`, and `README.md` files to your GitHub repository.

The `free-samples` folder is for public sample PDFs.

**Important:** Do not upload paid PDFs to a public GitHub repository. Paid files need protected storage and payment verification, which can be added later.
